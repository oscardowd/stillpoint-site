Study focus

An iPhone app blocker for study sessions that covers the risky hours.

Stillpoint helps you block distracting apps and websites during revision, library work, and exam prep. Start a study block in seconds, schedule the hours that usually collapse, and make it harder to bail out when concentration drops.

Why it fits study

Study drift is predictable enough to plan around.

Most study sessions fail in the same places: the first ten minutes before you start, the mid-block impulse to check one app, and the evening window where scrolling eats the whole plan. Stillpoint is useful because it can cover all three with the same block list and schedule system.

  • Start one-tap focus blocks when you sit down to work.
  • Block websites and social apps that usually break revision momentum.
  • Set recurring study windows for afternoons, library sessions, or exam week evenings.
Practical setups

Three ways students can use Stillpoint right away.

Before class

Use a short pre-lecture block.

Set a 20-minute block for reading or lecture prep so your phone is already quiet before class starts.

Library sessions

Protect the first hour.

Pick a longer block list and start a 45- or 90-minute session when you sit down, before the checking habit gets going.

Exam week

Pre-schedule the weak evenings.

Use recurring weekly schedules to cover the same risky hours every night instead of renegotiating them each day.

Strong boundaries

Raise the cost of “just one check.”

Use Face ID, PIN, and Screen Time hardening guidance if you know you tend to break your own rules once the session gets uncomfortable.
